## 📍 2. 단계별 온보딩 체크리스트

### [ 단계 1 ] 요청 접수 및 권한 승인 (D-14)
- [ ] **HR 요청 접수:** 신규 입사자 명단(CSV) 수신 및 정보 확인
- [ ] **기본 권한 검토:** 직무(Role) 기반 기본 권한(RBAC) 템플릿 매핑
- [ ] **고권한 승인 확인:** Cloud 인프라, 시스템 관리자 등 고권한 필요 시 부서장 승인 내역 점검
- [ ] **IT 자산 재고 확인:** 지급 기준에 맞는 디바이스(Mac/Windows) 및 모니터/주변기기 여유 재고 확인

### [ 단계 2 ] 입사 전 환경 구성 (D-7 ~ D-1)
- [ ] **계정 자동화 스크립트 실행:** `account_setup.py` 실행을 통한 사내 이메일 및 SSO 계정 자동 생성
- [ ] **라이선스 자동 할당:** 기본 SaaS(사내 메신저, 사내 위키, VPN, 사내 생성형 AI 챗봇 등) 및 직무별 라이선스 권한 부여 확인
- [ ] **MDM(Intune) 사전 등록:** 디바이스 시리얼 번호 기반 Autopilot / ADE 등록 완료
- [ ] **보안 정책 사전 배포:** 디스크 암호화(BitLocker/FileVault), 화면 잠금, EDR(백신) 정책 배포 확인

### [ 단계 3 ] 입사 당일 세팅 (Day 1)
- [ ] **디바이스 지급:** 신규 입사자에게 IT 자산 세트 지급 및 수령 서명 확인
- [ ] **최초 로그인 및 MFA:** 사내 중앙 계정 최초 로그인, 임시 비밀번호 변경 및 MFA(OTP) 등록 가이드
- [ ] **네트워크 접속 확인:** 사내 표준 Wi-Fi(`Company-Corp`) 및 원격 VPN 정상 연결 테스트
- [ ] **보안 및 IT 교육:** 사내 보안 정책, 자산 반납 규정, Self-Service/FAQ 활용 가이드 안내

### [ 단계 4 ] 운영 안정화 및 자산 등록 (Day 7)
- [ ] **단말기 보안 점검:** `device_check.py` 실행을 통한 최종 Compliance(패치, 암호화, EDR 구동) 통과 여부 확인
- [ ] **자산 대장 현행화:** `asset_inventory.csv` 대장에 Asset Tag, Serial, MAC 주소, 할당 사용자 정보 최종 업데이트
- [ ] **사용자 피드백:** 초기 권한 누락 여부 확인 및 추가 라이선스/소프트웨어 필요 사항 점검
