# 📝 사내 IT 지원 표준 요청 양식 (IT Request Form)

사내 IT 인프라팀은 임직원 여러분의 안정적인 업무 환경과 빠른 문제 해결을 지원합니다.
동일 문의 반복 감소 및 신속한 장애 대응을 위해 아래 양식에 맞추어 요청 내용을 작성해 주시기 바랍니다.

---

## 👤 1. 요청자 정보
* **이름:** (예: 김다현)
* **소속 부서:** * **직무(Role):** * **연락 가능한 사내 메신저 ID 또는 연락처:** * **지급받은 자산 번호 (Asset Tag):** (예: AST-PC-26001 / 모를 경우 생략 가능)
* **사용 중인 디바이스 및 OS:** (예: MacBook Pro / macOS 14, Windows 11)

## 🏷️ 2. 요청 유형

### 🚨 장애 (Incident)
업무 수행 중 발생한 시스템 또는 디바이스 장애
- [ ] 로그인 실패 및 인증 오류
- [ ] 사내 Wi-Fi 또는 VPN 연결 문제
- [ ] 디바이스 및 주변기기 고장
- [ ] 소프트웨어 실행 오류
- [ ] 시스템 속도 저하 및 비정상 동작
- [ ] 기타 장애

### 💡 일반 요청 (Service Request)
업무 지원 및 권한/설치 요청
- [ ] 표준 소프트웨어 설치 요청
- [ ] SaaS 라이선스 할당 요청 (예: 사내 생성형 AI 챗봇, 사내 교육 플랫폼 등)
- [ ] 시스템/인프라 접근 권한 요청
- [ ] IT 자산 교체 또는 추가 지급 요청
- [ ] 사내 계정 생성/변경 요청
- [ ] 기타 일반 IT 문의

## ⚡ 3. 긴급도 (Priority)
아래 항목 중 하나를 선택해 주세요.
- [ ] **Critical (긴급):** 전체 또는 다수 인원의 업무가 전면 중단된 상태 (예: 전사 네트워크 장애, VPN 전체 장애)
- [ ] **High (높음):** 단일 사용자의 핵심 업무 수행이 불가능한 상태 (예: 디바이스 부팅 불가, 필수 시스템 로그인 실패)
- [ ] **Medium (보통):** 업무 수행은 가능하나 일부 기능 제한 또는 불편이 있는 상태 (예: 특정 소프트웨어 오류, 성능 저하)
- [ ] **Low (낮음):** 업무에 지장이 없는 단순 문의 및 일반 요청 사항 (예: 라이선스 추가 신청, 일반 사용법 문의)

### [제목]

### [발생 일시]

* 어떤 구체적인 증상이 발생했나요?
* 현재 업무 영향 범위는 어느 정도인가요?
> (내용 작성)

### [오류 메시지 / 스크린샷 캡처 자료]
* 화면에 표시된 오류 코드 또는 시스템 메시지를 기재해 주세요. (스크린샷 첨부를 권장합니다.)
> (내용 작성)

### [재현 가능 여부]
- [ ] 항상 동일하게 발생   - [ ] 간헐적으로 발생   - [ ] 1회만 발생 후 재현 안 됨

## ✅ 5. 제출 전 사전 확인 사항 (필수 체크)
신속한 장애 해결을 위해 아래 기본 조치 사항을 먼저 수행해 주시기 바랍니다.
- [ ] 사내 IT FAQ(Self-Service 가이드)를 먼저 확인하고 조치를 시도했습니다.
- [ ] 디바이스를 재부팅(Reboot)한 후 동일 증상이 발생하는지 확인했습니다.
- [ ] Wi-Fi 네트워크 안테나 상태 또는 원격 VPN Client 연결을 재시도했습니다.
- [ ] 현재 사용 중인 OS 및 인프라 에이전트의 최신 업데이트 적용 여부를 확인했습니다.

## 📢 6. IT 인프라팀 안내 사항
* 일반 문의 및 서비스 요청(Medium/Low)은 영업일 기준 24시간 이내에 1차 검토 및 응답을 제공합니다.
* 시스템 접근 권한 신청 및 고권한(Admin) 계정 할당 요청은 직속 부서장 승인이 완료된 건에 한하여 처리됩니다.
* Critical(긴급) 등급의 장애 발생 시, 본 양식을 접수하신 후 사내 메신저 내 IT 긴급 지원 채널을 통해 인프라 담당자에게 즉시 실시간 공유해 주시기 바랍니다.
